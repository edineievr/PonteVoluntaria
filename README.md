# Ponte Voluntária

Plataforma que conecta pessoas dispostas a se voluntariar a projetos sociais.
Primeiro projeto: GACCH – Grupo de Apoio às Crianças com Câncer e Hemopatias (Marília-SP).
Projeto Integrador Extensionista · ADS.

## Requisitos

- Git
- Vite+ (comando `vp`): https://viteplus.dev

## Como rodar

1. Clone o repositório e entre na pasta:

   ```
   git clone https://github.com/edineievr/PonteVoluntaria.git
   cd PonteVoluntaria
   ```

2. Instale as dependências: `vp install`
3. Copie `.env.example` para `.env`
4. Terminal 1, inicie a API: `vp run api`
5. Terminal 2, inicie o frontend: `vp dev`
6. Abra http://localhost:5173
